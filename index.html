Robot Security

RoboShield v2: ROS 2 Robot Command Firewall

An inline gateway that sits between the operator's network and the robot and is the only path to it. Every command is checked against joint limits, step jumps, NaN values, rate limits and replayed stamps, then forwarded, clamped, dropped, or the robot is locked down at its last safe pose. Bridges two ROS 2 domains with SROS2 on the WiFi side, drops spoofed publishers message by message, and streams incidents to a SIEM tagged with MITRE ATT&CK for ICS. v1 was a passive RTPS packet watchdog; v2 moves from detecting to preventing.

ROS 2 Jazzy Rust (rclrs) Python SROS2 nftables MITRE ATT&CK for ICS
GitHub Repo
Engineering Challenge

rclrs had no way to tell which node sent a message, so spoofed commands couldn't be dropped individually. Vendored a one-field rclrs patch to map publisher GIDs to node names, with a fail-closed grace period for the discovery race.
